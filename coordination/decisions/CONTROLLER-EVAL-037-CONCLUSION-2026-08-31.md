# Controller — EVAL-037 Conclusion and Programme Disposition — 2026-08-31

## Status

**APPROVED CONTROLLER CONCLUSION.**

EVAL-037 is closed for the purpose of deciding whether Canon is worth carrying forward into the product architecture.

## Decision

The Controller accepts the following bounded conclusion:

> **Canon helps, but the current Canon retrieval / consumption system is not mature.**

This is sufficient to stop broad Canon-value discovery and return the programme to outcome-oriented product development.

## What the decision means

1. Canon remains a first-class component of the intended intelligence layer.
2. The programme no longer needs another broad experiment whose primary question is merely whether Canon can add value.
3. The current retrieval implementation is **not** accepted as the production retrieval design.
4. Optional free-form retrieval, unbounded retrieval, and the current search/read interaction must not be mistaken for the final product mechanism.
5. Future retrieval work, when authorised, must be justified by accepted-outcome improvement, repeatability, latency/context cost, or CpAO — not by retrieval sophistication for its own sake.

## Evidence basis

The Controller reviewed:
- the original frozen EVAL-037 design;
- completed NO_CANON and FULL_CANON lanes;
- repaired and supplemental retrieval treatments;
- the controlled Sonnet and controlled Gemma retrieval evidence;
- four independent blind judgment streams over the surviving image/video production packages.

The full intended 144-trial matrix did not complete symmetrically. This decision therefore accepts a programme-direction result, not a universal quantified treatment effect.

Detailed synthesis:
eval/experiments/EVAL-037/CONCLUSION.md

## Retrieval finding

The experiment established a clear implementation problem:

- optional Canon may be ignored;
- unbounded Canon may overwhelm model/provider context;
- bounded objective-driven retrieval is executable and competitive;
- models frequently consume ranked search results without following through to detailed reads;
- therefore the current retrieval protocol is immature.

## No further EVAL-037 execution

Do not:
- rerun failed lanes to improve symmetry;
- rerun merely for cleaner accounting;
- expand the model roster;
- launch another broad Canon/no-Canon experiment;
- generate all surviving media as a condition of accepting this conclusion.

Preserve existing evidence and branch provenance.

## Programme disposition

Return to planning mode.

The next Controller task is to rebase the T3-T8 programme around the shortest path to the final product shape:

customer request
-> intelligence / Canon
-> production specification
-> route selection
-> media execution
-> evaluation
-> bounded repair
-> accepted outcome
-> empirical memory,

measured by accepted-outcome rate and Cost per Accepted Outcome.

No paid execution or new implementation tranche is authorised by this decision.
