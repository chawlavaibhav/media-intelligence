## 0. A material limitation on this run — read before trusting any evidence line

This session's egress policy is a **strict allowlist**. `WebSearch` works (it executes API-side), but
`WebFetch` could not reach **a single external host**. Confirmed blocked, each returning
`EGRESS_BLOCKED` from the agent proxy:

| Host attempted | Why it was wanted |
|---|---|
| `inc42.com` | FAST42 2026 list of fastest-growing D2C brands |
| `entrackr.com` | funding snippets |
| `storyboard18.com` | Farmley media-spend article (directly relevant) |
| `www.thewholetruthfoods.com`, `sleepyowl.co` | brand sites / PDPs |
| `www.amazon.in` | marketplace listings, prices, packshots |
| `en.wikipedia.org` | sanity check on whether *anything* renders |

`/root/.ccr/README.md` is explicit that a 403/407 of this kind is an organisation egress-policy denial
and must be reported, not routed around. It was not routed around.

**The consequence, stated plainly:**

- **There are zero `OBSERVED` evidence items in this run.** Not one page was fetched and seen.
- Every evidence line below is **`INFERRED (search-summary)`** — a search engine's summary of a page
  this session could not open. It is real, dated, second-hand information. It is *not* primary evidence.
- Therefore **no SKU price, pack shot URL, PDP launch badge, current ad creative, follower count,
  YouTube library or job posting in this run has been verified by this agent.**
- Scores on the two criteria that depend on seeing the brand's actual advertising — **CURRENT CREATIVE
  OPPORTUNITY/GAP** and **PRODUCT / REFERENCE ASSET QUALITY** — are the weakest numbers in this file
  and are scored conservatively for that reason. Confidence is capped at MEDIUM for every brand.
- The dossiers name **candidate** asset sources by URL. Those URLs are *unverified* and must be opened
  by hand before any production work uses them.

**Standing note (applies to every run):** *Meta Ad Library + Instagram check recommended by hand for
the Top 3 before spend.* On this run that is not a recommendation but a **precondition** — the
"current creative" reading for all three top brands is inference from press and nothing else.

**Recommended fix for future runs (Controller action, one line):** allow this scheduled environment
to reach brand websites and the trade press (at minimum `inc42.com`, `entrackr.com`,
`storyboard18.com`, `afaqs.com`, `indianretailer.com`, `yourstory.com`, `amazon.in`, and arbitrary
brand domains). Without it, this workstream can rank prospects but cannot evidence them, and every
run will repeat this caveat.

1. **Salty** (88) — accessories are the single best physical match for what we can build today
   (hard-surface, non-skin, reflective hero product + code-composed price/offer overlay + short silent
   motion from the accepted still). Majority of its marketing budget is stated to be performance
   marketing; ~₹50 Cr run-rate is big enough to pay and small enough that three founders still read
   inbound; five new categories plus Salty Bags plus per-SKU offer creative across Blinkit, Amazon,
   Myntra and its own app is an obvious recurring volume story.
2. **Typsy Beauty** (84) — the freshest trigger in the run (funding announced **6 Aug 2026**, ~5.5
   weeks before this run), with **10+ product launches explicitly stated as imminent**, a premium
   ₹600–900 price point, and a simultaneous quick-commerce and offline push. Three named founders, CEO
   publicly identifiable. Creative-around-every-launch is the natural retainer.
3. **AntiNorm** (79) — ranked third on *probability* rather than value. A 2024-founded brand with three
   SKUs, up to seven launches planned, ₹28 Cr of Fireside money, hiring across growth, a single
   identifiable founder and no established creative partner is about as likely as it gets to actually
   reply to good unsolicited work. Ceiling is lower than Farmley's; odds are better.

**Deliberately flagged for the Controller:** **Farmley** scores level with Typsy (84) and is the
**highest-value-if-converted** prospect in the run — ₹370 Cr, profitable, near-100% digital media
spend, and squarely in the Controller's own FMCG/distribution competence. It is ranked 4th only because
a ₹370 Cr profitable company is the slowest to answer unsolicited work. If the Controller would rather
optimise for contract size than for reply rate, **swap Farmley in for AntiNorm.**

## 8. Production-capability dependency the Controller should see

This run selected brands. It cannot make the ad, and neither can anything else today:

- The runtime **has never called a provider**; all 14 battery runs are dry.
- `spend_authority.status: none` on every profile, and `dispatch_mode: live` refuses outright —
  live transport is deliberately unwired.
- Per `coordination/CONTROL-STATE.md` §9, a first paid run needs three things that do not exist:
  (1) a decision on whether the plan comes from a recorded fixture or a paid reasoning pass;
  (2) live transport behind `ExecutionBridge.run()`; (3) a signed runtime spend record.

So the prospecting loop is now **running ahead of the production loop**. That is not a defect in either
— but the first spec ad cannot be produced until those three exist, and this pipeline will accumulate
qualified brands in the meantime. Worth knowing before the next run adds another seven.

Two further constraints any spec ad from this pipeline must respect, both already reflected in the
hypotheses: exact copy must be **code-composed, never generated in-scene** (C-7), and no concept may
depend on a celebrity likeness (which is why MetaMan and Phitku were filtered out rather than ranked).
