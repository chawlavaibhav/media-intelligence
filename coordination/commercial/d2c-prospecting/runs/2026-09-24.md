### Method notes added this run

- **`/collections/<handle>/products.json?limit=N` is the fastest true trigger check.** It returns
  `published_at` per SKU, so a brand's *actual* launch cadence is readable first-hand in one call —
  far better than trusting a press date. This single call is what refreshed Mokobara's trigger and
  what exposed uppercase's stale one (§6). **Recommend this become a standing check.**
- **`sitemap_products_1.xml` is not at the store root** on many Shopify stores. Fetch `/sitemap.xml`
  first and follow the `<loc>` entries it indexes, or product counts come back as 0 (they did here
  for five stores until corrected).
- **The 114-byte empty body is now a recurring trap.** `ikonicme.com` and `solvedskin.com` both
  returned `HTTP 200` with a **114-byte** body this run — the same signature already recorded for
  Nothing But and SpinBot. Treat 114 bytes as "domain not established", never as "no ad tags".
- YouTube upload counts are most reliably read as **unique `"videoId"` matches** on `/@handle/videos`;
  the `accessibilityData` label parse returned nothing on current YouTube markup.
