## 10. What a future run should reuse

- **LocalSamosa's weekly "Brand Announcements, Launches and Releases"** is the best *current-trigger*
  source found so far — dated, brand-level, launch-level. Read it every run.
- **Inc42 FAST42 (the D2C growth ranking)** is a legitimate discovery pool of real operating brands
  in exactly the "large enough to pay, small enough to reach" band. It is **not** the same object as
  the "Top 20 Funded D2C Startups" index rejected in run 02. Its weakness is that it carries **no
  current trigger** — every FAST42 name still needs one.
- **Widen the pixel grep.** `"pixel_id":"…"` alone misses escaped web-pixels configs; use
  `pixel_id.{0,8}[0-9]{13,17}`. Four stores this run would have been mis-recorded otherwise.
- **Verify every domain and every YouTube handle before trusting it.** This run alone: `uppercase.shop`
  (dead), `uniqyou.in` (a school), `blueteaworld.com` (parked), `spinbot.in` (empty body),
  `assembly.com` vs `assemblytravel.com`, `bagline.in` → `bagline.com`, and `@uppercaseofficial`
  (a phone-case seller, not the luggage brand). Run 03 caught four such traps; this run caught seven.
