# Task RES-001: Evaluation corpus acquisition pilot

**TASK ID:** RES-001
**OBJECTIVE:** Acquire and validate the first independent evaluation-media corpus across several useful source families, with rights/access provenance, reproducible downloads, integrity checks and manifests, without constructing the final benchmark.
**WHY WE ARE DOING THIS:** Eval and later Canon evaluation need independent media. We need trustworthy, legally documented source material before designing holdouts or judging creative quality.

**INPUTS:**
- `coordination/PROJECT-CONTRACT.md`
- `resources/CHARTER.md`
- `resources/HANDOFF.md`
- `shared/AUTONOMY-POLICY.md`
- `resources/corpus/CORPUS-SOURCING-PLAN.md`
- approved candidate source families: Pitt Image and Video Ads; Personalized Visual Persuasion (PVP) if an official distribution can be verified; ImageReward/public image-preference datasets; AVA or comparable aesthetics dataset; KoNViD-1k; bounded LSVQ subset; VideoFeedback/public generated-video human-feedback datasets; official text-to-video preference/ranking datasets; bounded YouTube-UGC only if legitimately accessible

**IN SCOPE:**
- source discovery and official-source verification
- separate documentation of code licence, dataset/annotation licence, underlying-media rights, access terms, redistribution status and explicit commercial-use terms if stated
- reproducible/resumable download scripts for approved-access sources
- actual media acquisition where legitimate
- SHA256 checksums and deterministic media validation
- exact duplicate reporting; optional perceptual-duplicate report without silent deletion
- source registry and item-level manifests
- source bias/coverage report
- blocked-access / blocked-rights list
- small deterministic QA sample if needed for validation only

**OUT OF SCOPE:**
- no Canon experiments
- no GPT/VLM creative evaluation
- no model generation
- no new creative-quality labels
- no Canon-derived sampling strata
- no final benchmark/holdout construction
- no schema or architecture changes
- no paid APIs
- do not accept ambiguous terms or bypass authentication/access controls

**DELIVERABLES:**

- raw media stored locally under `resources/corpus/raw/<source_id>/` or another clearly documented local storage path; raw payloads must not be committed to Git

**AUTONOMY MODE:** autonomous

**RESOURCE BUDGET — Controller amendment 01, 24 Aug 2026:**
- sources/items: prioritize diversity over volume; aim for at least 3 distinct usable source/domain families if legitimately accessible
- retained/downloaded corpus target: 4–6 GB
- retained corpus hard stop: 8 GB
- local disk headroom: maintain at least 12 GB free space at all times; do not start a download/extraction that could violate this floor
- process sources sequentially rather than staging multiple large archives at once
- API spend: ₹0 / $0 paid APIs
- generations/retries: none
- other: official/author/lab distribution preferred; avoid unofficial mirrors, torrents, piracy and arbitrary website scraping
- archive deletion is permitted after successful extraction only if: (1) official source remains reproducibly downloadable, (2) exact source/version/URL is recorded, (3) download script is saved, (4) archive is fingerprinted before deletion and validated output is checksummed, and (5) extraction/validation completed successfully. Log deletion in the integrity report.
- if a source cannot fit while preserving disk headroom, take a smaller deterministic subset where legitimate or mark it `too_large_for_pilot`; never exceed the budget to hit a volume target

**CONTROLLER CLARIFICATIONS — 24 Aug 2026:**

1. **Which source list governs.** This task file governs the approved source families. `CORPUS-SOURCING-PLAN.md` is research context and a candidate pool, not a second approval list. A dataset from the plan may be used without further approval only when it clearly falls inside one of the approved source families above. A materially different source family requires Controller approval.

2. **PVP.** PVP means **Personalized Visual Persuasion**. Use that expansion only. If no official distribution can be verified, record it as unavailable / candidate-not-downloaded rather than guessing at a similarly named dataset.

3. **Intended use / licence bar.** RES-001 media is for **internal research and evaluation only**. No redistribution, customer delivery, training-data use or production use is approved by this task. A `research-only` label is not automatically sufficient: the source terms must clearly permit our actual internal evaluation use. If terms are non-commercial-only, academic-only, exclude commercial entities, or are ambiguous about our use, mark the source `blocked_license` or `metadata_only` and do not download the media.

4. **Login / terms gates.** Do not create accounts, sign in, accept click-through terms, provide API keys, request institutional access or otherwise cross an access gate on the user's behalf. For a candidate with such a gate, record `blocked_access` and continue to the next already-approved candidate. Escalate the whole task only if enough sources are blocked that the task success criterion cannot be met, if proceeding would require a human permission decision, or if a legal ambiguity affects material already downloaded.

5. **Known blocked candidates are evidence, not failure.** The pilot is allowed to conclude that many attractive datasets are unusable. Do not weaken the rights bar merely to reach three families or a byte target.

**SOURCE REGISTRY MINIMUM FIELDS:** source_id, canonical_name, domain, origin, official_url, citation/publication, media_type, provided_labels, human_annotation_type, dataset_size_claimed, downloaded_item_count, downloaded_bytes, access_method, code_license, dataset_annotation_license, underlying_media_rights, redistribution_status, commercial_use_status_if_explicit, terms/access_notes, version, timestamp, status, reason.

**STATUS VALUES:** downloaded | partial_download | metadata_only | blocked_access | blocked_license | too_large_for_pilot | unavailable | candidate_not_downloaded.

**ITEM MANIFEST MINIMUM FIELDS:** item_id, source_id, original_id, relative_path, media_type, extension, bytes, sha256, image dimensions OR video dimensions/duration/fps/codec where available, source_split, raw source labels/reference, download_status, validation_status.

**APPROVED DEPENDENCIES:** none beyond current charter and sourcing plan. Public source labels remain source observations, never project ground truth.
**STOP CONDITIONS:** storage or other resource budget would be exceeded; data-integrity failure; novel legal ambiguity affecting already-downloaded material; success criteria cannot be met without crossing an access/legal gate; need to redefine corpus domains or benchmark design. Candidate-specific login/terms/API-key gates are handled as `blocked_access` and skipped under Controller clarification 4 rather than bypassed.
**HUMAN APPROVAL TRIGGERS:** accepting uncertain rights, adding a materially different source family beyond the approved categories, exceeding budget, using media beyond internal research/evaluation, or crossing any account/terms/access gate.
**RESULT LOCATION:** `resources/tasks/RES-001-CONTROLLER-BRIEF.md` plus the deliverables above.
