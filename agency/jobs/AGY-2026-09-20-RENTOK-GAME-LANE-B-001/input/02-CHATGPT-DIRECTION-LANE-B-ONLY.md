Working title: PG OWNER — LEVEL UP!
The advertisement is an original retro platform game about the everyday challenges of managing a PG.
The central character is a small fictional PG owner, identifiable through a key ring and simple property-manager styling.
The character enters a difficult game level containing obstacles representing tenant verification, overdue rent, tenants leaving with unpaid dues, reconciliation, and complaints.
The player initially struggles, loses health, and becomes trapped by the obstacles.
A game-style cheat code appears:
CHEAT CODE UNLOCKED: INSTALL RentOK
The character activates RentOK and obtains an arcade-style power-up called the RentOK Control Blaster.
The power-up allows the player to run forward, overcome the obstacles, and transform them into completed or manageable operational tasks.
The game becomes visibly easier.
The player reaches the finishing flag and completes the level.
The advertisement concludes with RentOK branding and an app-install call to action.

## Proposed 30-second sequence

00:00–00:03 — Game introduction
A retro-platformer start screen appears.
The PG-owner character enters the game with three hearts.
On-screen title: "PG OWNER — LEVEL 01".
Arcade music and a start-game chime establish the gaming environment.

00:03–00:09 — Operational obstacles
The character encounters a giant unverified-document obstacle, overdue-rent enemy, and an unpaid-exit obstacle.
The player attempts to overcome them but loses health.
Use short, readable labels to establish the problem represented by each obstacle.

00:09–00:13 — The difficult level
A large reconciliation monster blocks the path.
A complaint obstacle appears.
The player is cornered with one heart remaining.
The game freezes.
A cheat-code message appears.

00:13–00:17 — RentOK activation
An in-game smartphone appears.
RentOK is installed and activated.
The character receives the RentOK Control Blaster, and the world transitions from chaotic to controlled gameplay.
The health counter is restored.

00:17–00:25 — The power-up sequence
The character runs forward and uses the new ability to clear the obstacles.
Each cleared obstacle triggers a task-specific visual transformation:

* Tenant verification becomes a completed verification record.
* Overdue rent becomes a payment reminder or tracked due.
* An unpaid-exit obstacle becomes visible outstanding dues.
* Reconciliation becomes an organized report.
* A complaint becomes a tracked service ticket.

The character should physically interact with the game obstacles, rather than merely running past labels that disappear automatically.

00:25–00:30 — Victory and CTA
The character reaches the finishing flag.
"LEVEL COMPLETE!" appears.
The game transitions to RentOK branding and an app-install CTA.
Working closing message:
"PG MANAGEMENT? LEVEL UP WITH RentOK."
