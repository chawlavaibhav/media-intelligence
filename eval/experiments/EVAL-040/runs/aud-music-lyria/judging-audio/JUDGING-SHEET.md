# Blind judging - aud-music-lyria (music; Lyria set - ElevenLabs direct follows as a second set)

Four 30-second tracks L01-L04, order shuffled. For each: (1) judge the RAW track (.wav) against its case contract; (2) then watch the STACKED view (.stacked.mp4: the same track laid under an accepted multi-shot clip by code) and add a fit-to-cut note. Verdict = the raw track; the fit note is separate.

Duration note: every Lyria track measures 32.8 s against a 28-32 s contract window; that is a fixed property of the route (trimmable by code at no cost). Say whether you reject on duration or judge the music and let the trim be a routing note.

## MUS-01 - tracks L01, L04 (stacked under VID-MS-02)
- ACCEPT only if the track is 28–32 s long and has no sung or spoken words.
- REJECT if drums or heavy percussion dominate the mix, or if an orchestral string or brass swell is present.
- ACCEPT only if at least one recognisably Indian instrument colour (flute/bansuri or tabla-like percussion) is audible.
- REJECT if the file is silent, clipped or ends with an abrupt cut mid-phrase.

## MUS-02 - tracks L02, L03 (stacked under VID-MS-01)
- ACCEPT only if the track is 28–32 s long and has no sung or spoken words.
- ACCEPT only if the energy audibly builds from the start to the end (more elements or a stronger pulse by the last third).
- REJECT if there is a large orchestral or 'trailer' swell, or if the arrangement is so dense it would mask street ambience.
- REJECT if the file is silent, clipped or ends abruptly mid-phrase.
