**FAILURE_PREVENTION**  
1. **Dial color drift:** Use a color reference card in setup; confirm blue is saturated and cool-toned (not muddy, not purple). If using generative tools, include explicit color-hex reference (e.g., #0B3D7D or similar deep blue) in prompts.  
2. **Hand/marker legibility:** Ensure baton markers and dauphine hands are not blurred or obscured by depth-of-field. Sharpen selectively during post if needed, but do not artificially enhance beyond physical realism.  
3. **Sapphire clarity:** If photographing, clean crystal obsessively before shoot. If rendering, add a realistic reflection line or subtle lens flare to signal the dome without overstatement.  
4. **Strap geometry:** If photographic, ensure leather is positioned naturally (not artificially stretched or kinked). If rendered, use a real leather shader with displacement and normal maps, not a flat material.  
5. **Wrist integration:** Avoid uncanny hand geometry (wrong proportions, unnatural angle). If rendering, use a credible hand asset; if photographing, use a genuine model and frame so proportions read naturally.  
6. **Aspect ratio:** Lock 4:5 early. Do not crop or re-frame at the end, as this risks losing critical product detail or introducing compositional imbalance.  
7. **Generative artifact rejection:** If using AI-generative imagery, do a final pixel-by-pixel comparison of dial markings, strap stitching, and case geometry against the specs. Reject any where the watch has been "perfected" or subtly re-designed (e.g., fewer markers, different hand shapes, missing texture).
