RESEARCH_NEEDS:
How to build strict typographic/information hierarchy so price is the dominant, immediately-legible element without decorative noise.
How to signal "serious infrastructure" rather than "discount promotion" through pricing framing and visual restraint (India-specific pricing psychology).
How to encode festive/cultural signal legibly and briefly without literal festive clipart, consistent with how Indian visual communication compresses culture into minimal cues.

FINAL_PRODUCTION_PACKAGE

DELIVERABLE
One static 4:5 poster, master file 2400×3000 px (scalable to 1080×1350 for social), RGB, print-safe margins. Single image, single concept, no variants.

OBJECTIVE_INTERPRETATION
The customer needs a festive-season acquisition poster for an API product whose entire commercial hook is two prices (₹9 image / ₹99 video). The stated risk is that low, round rupee numbers read as "discount flyer" unless the design frames them as engineered, infrastructure-grade pricing. Because aight's own site voice is plain, declarative, and proof-of-seriousness driven (prepaid rupees, one GST invoice, a founder who answers), the poster's credibility must come from the same register: precision, restraint, and a rate-card logic — not festive clipart or retail sale mechanics. Typography and hierarchy must therefore carry both the emotional (festive, premium) and functional (price, comprehension) load, since no product photography exists to lean on.

CORE_CREATIVE_IDEA
"The Festive Rate Card." The poster is composed like a utility/telecom tariff card or a GST invoice header — a format Indian businesses already read as official, exact, and non-negotiable — rather than like a sale flyer. Two prices sit in a tabular, equal-weight rate table. Festivity is carried by a single restrained device (a hairline gold rangoli-lattice border and a warm lamp-glow gradient), never by literal diyas, fireworks, or "OFFER/SALE" iconography. The pitch to the viewer is implicit: this isn't a discount, it's what the infrastructure actually costs — echoing the site's own framing of pricing as structural (prepaid, capped, invoiced) rather than promotional.

MESSAGE_AND_INFORMATION_HIERARCHY
1. Price pair (₹9 / ₹99, tabular, largest type on the page) — the single thing every viewer must retain, legible even at thumbnail size, no cultural code required to parse it (numerals travel universally).
2. Unit labels ("IMAGE GENERATION" / "VIDEO GENERATION") — disambiguate the two prices instantly.
3. Trust line ("Prepaid rupees. One GST invoice. No surprise bills.") — converts low price into infrastructure credibility, sourced verbatim in spirit from the site's own proof points.
4. Wordmark + tagline ("aight. — Where Indian businesses buy AI") — brand anchor, deliberately modest in size relative to the price.
5. Festive frame line ("Festive-season infrastructure pricing") — supplies seasonal context without discount language.
6. CTA ("Talk to us — getaight.ai") + fine-print rate disclaimer — lowest priority, smallest type.
Everything below tier 1 is optional to a skimming viewer; nothing above tier 1 is allowed to compete with it in size or contrast.

VISUAL_SYSTEM
Palette: near-black charcoal background, off-white type, single antique/brass-gold accent. No red/yellow "sale" colors, no multicolor festive gradient.
Grid: strict single-column vertical grid, generous margins, center third reserved for the price block, top for wordmark, bottom for CTA/legal — structure emerges from grouping like-with-like information (price data together, trust data together, brand data together), so the layout reads as inevitable rather than decorated.
Typography: one grotesk/neo-grotesque sans family across the whole poster, varying only weight and size; tabular (lining) figures mandatory so ₹9 and ₹99 share a baseline grid like a real rate card; small caps + letterspacing for labels to reinforce "spec sheet" tone.
Motif: a single 1–2pt hairline border built from a repeating rangoli-derived diamond/dot lattice, running the full frame edge — geometric and architectural, not ornamental, so it reads as festive to an Indian viewer while still looking engineered. A soft warm glow in the upper third evokes lamplight without depicting a lamp.
No product photography, no people, no icons of AI (no robots/circuits), since the product is invisible infrastructure — the type system itself must do all persuasive work.

PRODUCTION_RECIPE
1. Generate the text-free background/texture/motif layer (prompt below).
2. Set all copy and numerals as vector type in a design tool on the grid specified above (deterministic, not generated).
3. Composite type over background; apply the gold hairline divider between the two price rows.
4. QA pass at three sizes: full res, 1080px feed, 300px thumbnail — confirm ₹9 and ₹99 remain instantly legible and correctly rendered at all three.
5. Final color-grade/contrast check (off-white text ≥ 4.5:1 contrast against charcoal); export 4:5 master and social crop.

DETERMINISTIC_OR_NON_GENERATIVE_ELEMENTS
All text is deterministic vector type, never generated as pixels, because price accuracy is a hard constraint and generative text rendering of currency symbols/numerals is unreliable at this stakes level:
- Wordmark: "aight." — off-white, modest size, top-left.
- Tagline: "Where Indian businesses buy AI" — Light weight, 60% opacity, beneath wordmark.
- Price row 1: label "IMAGE GENERATION" (small caps, gold, letterspaced) + numeral "₹9" (Bold/Black, off-white, tabular figures, largest element on page) + suffix "/ generation" (Light, 70% opacity).
- Gold hairline divider rule (same gold as border motif) between the two price rows.
- Price row 2: label "VIDEO GENERATION" + numeral "₹99", identical size/weight/treatment to row 1 so both prices carry equal visual authority.
- Trust line: "Prepaid rupees. One GST invoice. No surprise bills." — off-white, medium weight, centered.
- Festive frame line: "Festive-season infrastructure pricing" — small, gold, no "SALE/OFFER/DISCOUNT/% OFF" wording anywhere on the poster.
- CTA: "Talk to us — getaight.ai" inside a slim outlined pill, off-white.
- Fine print, bottom corner, low opacity: "Introductory festive-season rate. Terms at getaight.ai."
All grid positions, type sizes, tracking values, and color hex codes are locked in production spec before compositing — no randomness permitted in this layer.

FAILURE_PREVENTION
- Currency/numeral misrendering → mitigated entirely by rendering ₹9/₹99 as deterministic vector type, never generated text.
- Drifting into "discount flyer" territory → banned assets: starbursts, ribbons, "%", red/yellow sale colors, countdown/urgency language; enforced by rate-card tabular layout instead.
- Festive motif turning kitsch/stock → motif restricted to one abstract geometric lattice + one glow, no literal diya/firework/confetti imagery, per construction plan.
- Hierarchy collapse from clutter → hard cap of six copy blocks total; if any block competes visually with the price numerals in size or saturation, it is downsized in QA.
- Illegibility at small/thumbnail sizes → mandatory three-size QA pass before export; tabular lining figures and sufficient weight chosen specifically for compression survival.
- Overclaiming/legal exposure on "festive rate" → fine-print disclaimer included by default.
