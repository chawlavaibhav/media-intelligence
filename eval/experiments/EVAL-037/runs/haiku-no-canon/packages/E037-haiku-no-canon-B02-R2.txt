**FAILURE_PREVENTION**

1. **Numbers must read instantly:** Use 60+ pt for ₹ symbol + digits. Test at mobile thumbnail size.
2. **Avoid "discount retailer" reads:** 
   - No garish colors, no clip-art, no festive decorations (lights, rangoli, etc.).
   - Ensure background is solid/minimal. No busy patterns.
   - Use restraint with any accent color—one thin accent line, not splashes.
3. **GST invoice line is credibility:** Verify spelling: "One domestic GST invoice" (from website language).
4. **Currency symbol clarity:** Use rupee (₹) consistently, not "Rs."
5. **Contrast check:** Test white text on charcoal at 14pt (sub-headline minimum readable size) against WCAG AA standard (7:1 contrast ratio).
6. **Spacing discipline:** Use grid multiples (8 or 16 px). Avoid optical imbalance—weight should favor top (headline) and push CTA to absolute bottom.
7. **No typos:** Proofread "getaight.ai" URL and brand line word-for-word against website.
