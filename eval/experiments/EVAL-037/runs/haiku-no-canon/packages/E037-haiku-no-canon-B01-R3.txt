### FAILURE_PREVENTION

**Risk 1: Chaos section feels generic/not Indian.**
- *Prevention:* Use Hindi/English code-switching in dialog fragments. Show actual tools (WhatsApp, notebooks, the spreadsheets Indian PG owners actually use). Use warm, lived-in environment, not sterile.

**Risk 2: Solution feels too fast/unrealistic.**
- *Prevention:* Show multiple operations (rent, KYC, complaints, attendance) so it's clear RentOK does *everything*, not just one thing. Pace allows time for each feature to register.

**Risk 3: Emotional arc doesn't land.**
- *Prevention:* Use same actor in both sections so relief/transformation is personal and visible. Close-up on face matters.

**Risk 4: Viewers don't understand what problem is solved.**
- *Prevention:* "Before" is tactile and loud so pain is visceral. "After" is quiet and clear so contrast is automatic. No voiceover explanation needed.

**Risk 5: App screens look generic or don't match actual RentOK UI.**
- *Prevention:* Use real RentOK app screenshots and compose them into the video, or generate UI mockups that match the actual app's design language (visible on website: clean, simple, green accents).
