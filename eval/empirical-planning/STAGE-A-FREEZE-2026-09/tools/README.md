# tools/ — the generator that emits this package

Run from the repo root: `python3 eval/empirical-planning/STAGE-A-FREEZE-2026-09/tools/build.py`. It reads only committed repository files — the two compiled packs, `canon/packs/pack-triggers-v0.yaml`, the campaign plan (for the verbatim E1–E5 lines) and `eval/empirical-planning/ROSTER-REFRESH-2026-09.yaml` (prices and pins by route key, cross-checked at build time) — and deterministically rewrites every file in the package directory: `TEST-CASES.yaml`, `test-cases/*.md`, `BLUEPRINTS/*.blueprint.md` (sha256 recorded per case), `ACCEPTANCE-CONTRACTS.md`, `IRREDUCIBILITY.md`, `ELIMINATION-RULES.md`, `COVERAGE-MATRIX.md`, `SEED-POLICY.yaml`, `EVALUATOR-PLAN.yaml`, `COST-TABLE.yaml`, `README.md`. No network and no API call of any kind; USD 0. `MI_REPO` / `MI_OUT` may override the repo root and output directory for a scratch rebuild. Case data lives in `cases_img.py`, `cases_vid.py`, `cases_aud.py`; the route catalogue in `routes.py`; the README template in `readme.py`. The EVAL-039A Tester reproduced 79/79 package files byte-identical from this generator (run from the session scratchpad, roster at commit `97b237f`) before the post-Tester corrections; after a roster change, rebuild here rather than hand-editing totals.
