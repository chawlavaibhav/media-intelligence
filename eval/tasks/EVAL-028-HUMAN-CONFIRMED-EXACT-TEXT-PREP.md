## Composite design

Freeze a new family/contract; do not reinterpret OCR contract v1.

Preferred flow:

1. automated stage produces `candidate_match` or `reject`;
2. reject => final MISMATCH, no human review;
3. candidate_match => send image independently to reader A and reader B;
4. neither reader sees:
   - target;
   - source/ground-truth transcription;
   - OCR result;
   - expected match/mismatch label;
   - other reader response;
5. each reader records:
   - exact transcription;
   - `cannot_read`;
   - `ambiguous`;
6. freeze both responses;
7. final MATCH only when both frozen transcriptions satisfy the frozen exact comparison rule against target and the contract's agreement rule;
8. disagreement/cannot_read/ambiguous => fail closed to MISMATCH / review-failure state, never MATCH.

Do not silently normalize beyond the existing accepted exact-text comparison semantics.

## A-TEXT handoff preparation

It must:

- show only generated image + opaque item ID to reader;

- preserve route/repeat metadata outside the human-facing surface;
- allow code-level target comparison only after both readers' files are frozen.

Do not score A-TEXT now.
