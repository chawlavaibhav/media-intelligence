# EVAL-040 — live runner + blind judging packet — Executor report (2026-09-08, USD 0)

**Built (all under `eval/harness-v2/`, no live call made, no key value read, Controller's `authorization.local.yaml` untouched):**
- `run_live.py` — `plan` / `smoke` / `execute` / `status`. `plan` draws the ordered trial list from `dry_run.build_manifest` over the requested cases (case-major; within a case every route's repeat 1 before any repeat 2), drops every `would_dispatch: false` row (conditional, no adapter, unverified, unpinned, needs_controller_enablement) with its reason, refuses an empty plan, an unknown case/route, a freeze package that differs from the authorisation's `item_basis_commit`, and never overwrites; writes `PLAN.yaml` + `PLAN.sha256`. `execute` refuses without a committed, unchanged plan or a permitted authorisation; opens/creates the ledger at `<out>/ledger/<run-id>/`; builds each adapter with the real urllib transport and `allow_default_token_source=True` (the only place in the package; a test greps for it); refuses a trial whose rendered body sha256 differs from the plan's; dispatches one at a time, 0 retries; `BudgetExceeded` (cap, raised before any send) stops the run with `RUN-STATE.json: stopped_cap_reached`; a pre-dispatch refusal or any other exception on one trial is recorded under `<out>/trials/` and the run continues; resume skips every trial with an attempt / refusal / harness-error record. After each artifact: `format_probe`, `gate_wrapper.run_post` (observation), and after repeat 2 `repeat_consistency` vs repeat 1 → `<out>/instruments/<trial_id>.json`; failures there are recorded on that file, never raised. `status` prints done/remaining, settled cost by pool, headroom (from the re-validated authorisation), errors.
- `judging_packet.py` — `build` copies every sealed artifact verbatim to `<out>/judging/J<nn>.<ext>` (seeded random permutation over the whole set, sha256 re-checked), writes `JUDGING-SHEET.md` (blind id + case id + ACCEPTANCE-CONTRACTS.md section at the plan's commit) and `VERDICTS.template.yaml`, refuses if any text file leaks a route key / model id / surface / adapter / pool / text-case arm / trial id (word-bounded scan), writes the reveal key ONLY to `<key-dir>/REVEAL-<run-id>.json` (key dir must be outside the repo) and a salted sha256 commitment to `judging/REVEAL-COMMITMENT.txt`; PNG text/EXIF/C2PA chunks, JPEG APP segments and WEBP EXIF/XMP are scanned and noted per trial in `<out>/judging-build/METADATA-NOTES.json` (outside the judge's directory; bytes never altered). `reveal` verifies the commitment, requires exactly one accept/reject per blind id in `judging/VERDICTS.yaml`, writes `RESULTS.yaml` per case × route × repeat (no artifact ⇒ reject, basis recorded) and applies E1/E2 per (route, question) with the planned count as denominator (E1 ≥ ceil(0.375 n): 8→3, 4→2; E2 ≤ floor(0.25 n): 8→2, 4→1), printing the table.
- One additive fix in `dry_run.py`: `_d2()` now coerces through `Decimal()` (a subset book with no INR row made `sum()` return `int 0`, which `.quantize` rejected). No other existing module changed.
