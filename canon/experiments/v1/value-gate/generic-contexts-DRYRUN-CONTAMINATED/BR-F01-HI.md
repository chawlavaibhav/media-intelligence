# Craft context

## Working out what matters most
A commercial layout can only have one thing that is noticed first. When a brief asks for several
elements to be prominent, that is not a layout problem to be solved by making everything large;
it is a decision about priority that has to be made before any layout begins. Decide what a
viewer must take away if they see the piece for only a moment, and let everything else be
arranged around that. Size, weight, colour contrast and position all compete for the same
attention, so using all of them on all elements cancels the effect.

## Handling conflicting instructions
Briefs often contain requirements that cannot both be satisfied. When two instructions conflict,
say so plainly rather than quietly choosing one. Offer a resolution and the reasoning behind it,
or state the assumption being made so it can be corrected. A plan that silently drops one of the
client's stated requirements will look complete and will fail review later.

## Register and tone
Words like traditional, modern, premium and friendly describe a feeling rather than a
specification. When a brief asks for two registers that pull against each other, blending them
usually produces something that reads as neither. It is generally better to let one register
lead and let the other appear in a specific, limited way — one element, one detail — so that both
are present without the piece becoming incoherent.

## Typographic decisions
Type carries meaning through more than the words. Weight, case, spacing and the relationship
between sizes all signal how formal, how urgent and how expensive something is. Where copy must
appear exactly as supplied, treat those strings as fixed content and design around them rather
than adapting them to fit a layout. Legibility at the size the piece will actually be viewed
matters more than how it looks at full size on a desktop screen.

## Offers and specifics
Concrete terms tend to be more persuasive than general claims. A specific number, a specific
deadline and a specific limit give a reader something to act on, where general assurances of
value do not. If the brief supplies specifics, keep them intact and prominent.

## Before finishing
Check that every required element is present, that nothing contradicts anything else, and that
the single most important message is still the first thing a viewer would notice.
