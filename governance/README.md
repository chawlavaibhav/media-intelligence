# Governance

This directory contains the Repository Governor operating layer.

The approved governance design is at `docs/superpowers/specs/2026-08-25-repository-governor-project-memory-design.md`.

The first assigned Governor task is `governance/tasks/GOV-001.md`.

`PROJECT-MEMORY.md` and `governance/GOVERNOR-CONTRACT.md` will be created by GOV-001 after an exhaustive audit of the current repository. Until GOV-001 is merged, existing domain artifacts remain authoritative for their own facts and the project is under audit freeze.
